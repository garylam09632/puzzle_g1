## Kickoff recommendation

**Start with Stage 00 (Product foundation).**  
It is short, decision-heavy, and unblocks brand, difficulty labels, and v1 scope. Do not skip it entirely.

**Then start Stage 01** as the first coding stage (app shell, home/play navigation, session polish on the existing demo puzzle). Stages 02–04 wait until Stage 01 exit criteria are met (or a conscious scope cut is recorded here).

Interim rule if you want to code in parallel: begin Stage 01 with a **working title** and the default tier set (Easy → Expert), and finish Stage 00 name/monetization decisions before store packaging (Stage 03).
